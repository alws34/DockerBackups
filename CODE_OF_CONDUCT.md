# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short: be respectful, assume good faith, and keep
discussion about the work.

## Scope

It applies in all project spaces (issues, pull requests, discussions) and when
someone represents the project elsewhere.

## Reporting

Report unacceptable behavior to the maintainer privately through the
repository's **Security** tab → **Report a vulnerability**
(<https://github.com/alws34/homelab-takeout/security/advisories/new>); mark the
report as a Code of Conduct issue. No email address is needed. Reports are
handled confidentially.

## Enforcement

The maintainer will review every report and may respond with a warning, a
temporary ban, or a permanent ban, following the
[Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
